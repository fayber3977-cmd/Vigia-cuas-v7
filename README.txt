VIGÍA C-UAS V7
Aplicación web progresiva de observación y registro.

PUBLICACIÓN:
Sube el contenido de esta carpeta a la raíz de un repositorio GitHub y activa GitHub Pages desde main / (root).

FUNCIONES:
- Cámara trasera y captura manual.
- GPS solicitado por el usuario y apertura de OpenStreetMap.
- Detección experimental de cambios entre fotogramas.
- Alertas sonoras opcionales.
- Historial local, estadísticas y exportación JSON.

LIMITACIONES Y SEGURIDAD:
La detección de movimiento NO es inteligencia artificial y NO identifica ni confirma drones. Puede activarse por cualquier cambio visual. No sirve para determinar si un objeto es una amenaza. La cámara del teléfono no permite identificar con certeza aeronaves.
Los datos se guardan en el almacenamiento local del navegador. Exporta evidencias antes de borrar datos o reinstalar. Usa la aplicación solo para observación segura y legal.
